# Contributing

MacAppFoundation is publicly available, but it is **not run as a community-maintained open-source project**.

The repository is maintained primarily for the author's own applications and priorities. Public visibility is intended for transparency and reference; it does not create an expectation of community governance, support, roadmap participation, or contribution review. Any use, modification, or redistribution of the source is subject to the repository's applicable license terms.

## Issues and support

Please do not rely on GitHub Issues as a support channel. Bug reports, feature requests, integration questions, and usage questions may not receive a response.

There is no support SLA and no commitment to implement third-party requirements.

## Pull requests

Pull requests are not actively solicited. They may be reviewed, closed, or left unanswered at the maintainer's discretion.

If your requirements differ from the package's current direction, maintain your own changes as permitted by the repository's applicable license terms.

## Roadmap

The roadmap is driven by the maintainer's own applications. Public discussion does not imply that a requested change will be accepted or scheduled.

## Releases

If you consume MacAppFoundation in another project, pin a released version you have validated and review release changes before upgrading. Do not assume compatibility or maintenance commitments beyond the published release itself.
