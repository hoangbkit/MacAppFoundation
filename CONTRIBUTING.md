# Contributing

MacAppFoundation is publicly available, but it is **not run as a community-maintained open-source project**.

The repository is maintained primarily for the author's own applications and priorities. Public visibility is intended to make the code useful for reference and reuse; it does not create an expectation of community governance, support, roadmap participation, or contribution review.

## Issues and support

Please do not rely on GitHub Issues as a support channel. Bug reports, feature requests, integration questions, and usage questions may not receive a response.

There is no support SLA and no commitment to implement third-party requirements.

## Pull requests

Pull requests are not actively solicited. They may be reviewed, closed, or left unanswered at the maintainer's discretion.

If you need behavior that does not match the package's current direction, the preferred approach is to fork the repository and adapt it for your own project.

## Roadmap

The roadmap is driven by the maintainer's own applications. Public discussion does not imply that a requested change will be accepted or scheduled.

## Releases

If you consume MacAppFoundation in another project, pin a released version you have validated and review release changes before upgrading. Be prepared to maintain a fork if your requirements diverge from the package's direction.
